KEYCARD {VERSION} - Windows build
=================================

A first-person, offline, single-player career simulator about hotel Loss Prevention.
Start as a night-shift LP Officer at the Veldane Grand Harbourfront (a fictional
hotel) and work toward Vice President, Global Safety & Security: 34 cases, four
career crises and a capstone across ten career levels, plus challenge modes
(survival, daily, classroom) with a local leaderboard.

RUN
  Portable zip:
  1. Unzip the whole folder anywhere you can write to (for example Documents\Games).
     Do not run it from inside the zip.
  2. Double-click Keycard.exe.
  Windows may warn that the publisher is unknown: see UNSIGNED-BUILD.txt.

REQUIREMENTS
  Windows 10 or 11, 64-bit. A DirectX 11 graphics card (tested on a GeForce GTX 1650:
  about 60 fps at 1920x1080 on the default High setting). About 1 GB of disk space.
  If the game reports missing runtime files, install the Microsoft Visual C++
  Redistributable (x64) from Microsoft's website.

CONTROLS
  WASD / arrow keys move, mouse looks, E or Enter interacts, J or Tab notebook,
  I inbox, Esc or P pause, F10 photo.
  Controller (Xbox layout): left stick moves, right stick looks, A interacts,
  X inbox, Y notebook, Menu pauses.
  Menus work with the keyboard (Tab/arrows, Enter/Space, Esc back).

SAVES
  Saved automatically, locally only (no accounts, no network):
    %LOCALAPPDATA%\Keycard\Saved\SaveGames\slot1.kcsave
  A backup is kept next to it. If the game reports a recovered save, it loaded the
  backup. Challenge results and the leaderboard are saved separately; they never
  touch your career. Certificates you save go to %LOCALAPPDATA%\Keycard\Saved\Certificates.

UNINSTALL
  Portable: delete the folder. Installer: Settings > Apps > Keycard > Uninstall.
  To remove saves too, delete %LOCALAPPDATA%\Keycard.
